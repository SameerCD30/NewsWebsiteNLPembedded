# Civic Grievance Reporting Platform using NLP for Issue Detection
Civic Grievance is a full-stack web application that enables citizens to report and track public infrastructure and civic issues. The system is built using React for the frontend, Spring Boot for the RESTful backend, PostgreSQL (Supabase) for data persistence, and a FastAPI-based NLP microservice for automated grievance validation and categorization. It implements JWT-based authentication and role-based access control to support citizens and administrators. Users can submit grievances with details such as title, description, category, and location, while the backend manages CRUD operations, status tracking, and secure API access. The NLP service analyzes submitted text to filter irrelevant reports and classify valid grievances before they are stored in the database, demonstrating a microservices-based architecture with AI integration.
